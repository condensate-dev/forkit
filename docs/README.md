# The forkit book

forkit brings Foundry-style fork tests to TypeScript. You fork real chains with anvil, fund accounts, impersonate, warp time, snapshot and revert, then assert on what actually landed, from inside vitest, bun:test, jest or node:test. Your production TypeScript runs against real mainnet state.

Start with [Getting started](getting-started/README.md) for your runner. If you know Foundry, the [cheatcode reference](reference/cheatcodes.md) maps every cheatcode to its forkit equivalent. The full table of contents is in [SUMMARY.md](SUMMARY.md).
