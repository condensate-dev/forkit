# forkit logo

The mark keeps the Condensate orb's three petals and splits its single iridescent seam into a fork: one pinned chain state diverging into independent test states. The fork is one filled path with a broad junction, so it stays readable at 16 px.

## Palette

| Role | Value |
|---|---|
| Petals and wordmark on light backgrounds | `#0c0e11` |
| Petals and wordmark on dark backgrounds | `#f2f3f5` |
| Seam gradient (the only colour) | `#a53afd` → `#6636fb` → `#1284fc` → `#00edfc` → `#46fafd` |
| Social preview tagline | `#aeb3be` |

## Files

| File | Use |
|---|---|
| `mark.svg`, `mark.png` (512 px) | The mark on light backgrounds: favicon, avatar, book cover |
| `mark-dark.svg`, `mark-dark.png` | The mark on dark backgrounds |
| `mark-alt.svg` | Runner-up direction, kept for reference |
| `lockup.svg`, `lockup.png` | Mark plus the "forkit" wordmark, light backgrounds |
| `lockup-dark.svg`, `lockup-dark.png` | Mark plus wordmark, dark backgrounds |
| `social.svg`, `social.png` | 1280 × 640 GitHub social preview |

Marks use a 1280 × 1280 viewBox; lockups are 1089 × 320. Every SVG is plain paths and one gradient: no fonts, filters, images or external references. The wordmark is Avenir Next Demi Bold converted to outlines. All files were rendered and checked at 16, 64 and 512 px. Use the mark alone below about 96 px wide; the lockup is not legible at favicon size.
